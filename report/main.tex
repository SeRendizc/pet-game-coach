{\normalsize
我做了一个能直接玩起来的 demo，并内置了「小芽」AI Coach，涵盖军师、陪练、老师三种角色感。游戏里的确定事实——伤害怎么算、谁先出手、哪些行动合法——全部由规则和结算器负责。

所以它不只是聊天机器人：模型不自己算伤害、不自己决定哪些行动合法、不编造历史，也不猜对手还没发生的那一手。固定规则能回答结构化的提问，但玩家可以用任意方式开口。一句「我是不是老舍不得换宠？」，要接住它得先读懂这是在问跨局的行为习惯，而不是某个伤害数字，再去翻跨局记录、当场数一遍换宠次数，最后把查到的几件事讲成一句解释。模型的价值就在这一步：把开放式语言映射到游戏状态、历史记录和知识查询上，再基于核验过的结果组织解释。

三种角色各解决一个问题：军师摆出这一回合的取舍并给出可查的依据，老师只用当时看得见的信息复盘讲解，陪练记得住、有情绪但不越界。为了让这三套标准同时成立，合法行动先由结算器算完；模型拿到一个受控的只读工具循环，最多调三次，工具名、参数、重复调用、次数与回执大小逐次由程序校验；回执与生成结果对不上就丢掉模型那句，退回本机结论。

最大的限制是没有真人数据：学习效果只做过离线实验和自动检查，不能说明有人真的学会了。
}
