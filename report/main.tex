{\small
我做了一个能直接玩起来的 demo，并在里面装了一个 AI Coach。游戏里的确定事实——伤害怎么算、谁先出手、哪些行动合法——全部由规则和结算器负责。

所以它不是聊天机器人：模型不自己算伤害、不自己决定哪些行动合法、不编造历史，也不猜对手还没发生的那一手。它负责的是理解玩家那句开放式提问、判断问题属于哪个角色、在允许范围内决定还要继续查什么，最后把已经核验过的结果讲成人能听懂的话。

三种角色各解决一个问题：军师摆出这一回合的取舍并给出可查的依据，老师只用当时看得见的信息复盘和讲解，陪练记得住、有情绪但不越界。为了让这三套标准同时成立，全部合法行动先由结算器算完，模型只拿到一个只读、有界的工具循环——最多三次，调用哪一类由代码判定，参数、预算与停止条件由宿主校验；回执与生成结果对不上就丢掉模型那句，退回本机结论。

最大的限制是没有真人数据：学习效果只做过离线实验和自动检查，不能说明有人真的学会了。
}
