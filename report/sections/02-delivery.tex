\section{交付了什么}

\textbf{军师。} 引擎枚举双方全部合法行动，对每一种组合跑一遍共享结算器，模型只负责把算好的事实讲成玩家能理解的取舍；双方同速时两种出手顺序各算一次，搜索不会偷偷利用随机数。局内主动提示也归军师而不是陪练，触发条件是代码里的五条：伙伴倒下、在两个选项间来回犹豫、真实枚举出来的明显策略错误、长停留，以及血量低于 35\% 而背包里还有药；安静档与「本局不再提醒」永远优先。

\textbf{老师。} 复盘分整局与单回合两层，再根据玩家在某个回合的真实选择出一道变式题。有一条硬规则：复盘一律使用回合开始时的公开状态，不使用对手实际打出的那一招——否则任何一次失败都能被解释成「你当时选错了」。这条有测试保证：改掉对手的实际行动，复盘结论不变。

\textbf{陪练。} 状态不是模型编的，而是从真实对战历史派生（连败几局、最近有没有赢、这台机器上有没有历史记录），再映射到四档语气，每档有字数与问句上限，档位本身会作为证据写进模型输入。主动开口只挂在两个事件上，每局各一次。教学账本记住已经教过的知识点，只有当军师独立观察到 3 次同类失误时才标回未掌握，并且说得出「为什么又教」。

\textbf{怎么跑。}

\begin{verbatim}
npm start        # Node.js 20+，无第三方依赖
\end{verbatim}

浏览器打开 \texttt{http://127.0.0.1:8765/}。顶部两个入口：训练按关卡挑战固定对手，对局里对手自由配队，也可以是同机分屏的两名真人，两边各有一条教练。\textbf{不接模型也能完整游玩，规则建议、复盘、培养建议和小测都不依赖模型；接入模型之后，这些解释改由模型生成。}密钥只留在后端进程内存里，不落盘。

\textbf{边界。} 语音已整体停用，联网 PVP 未做，依赖真人被试的验收没有完成，浏览器慢响应只有替换请求级别的验证。逐条写在第五节。
