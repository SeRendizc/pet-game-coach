\section{协作中的难点与解决}

分工是清楚的：\textbf{我更多负责顶层设计和真实测试，agent 进行具体实现和代码层面的测试。}架构、三种角色的边界、每条约束的判据由我定；单元测试交给 agent 写，可以并行推进。代价是「实现完了」和「功能生效了」是两回事：单元测试能验证一个函数内部对不对，验证不了这个函数有没有被接上，也验证不了它量的是不是该量的东西。这一章里的问题，都是这么漏出来、又被我一个个测出来的。

\subsection{代码是对的，功能没有生效}

有三件事的形态完全一样：代码看着对、\code{npm test} 全绿、功能根本没有生效。agent 新增的模块 \code{rules.js} 没有进静态资源白名单——磁盘上的白名单、测试、模块图全是对的，但我打开页面看到的还是白屏：运行中的那个进程拿的是旧白名单，\code{/rules.js} 返回 404，\code{app.js} 的 import 图整体失败，页面一行 JS 都不执行。陪练的主动气泡模板写好了，调用它的 \code{notify()} 却没有任何地方调用过，所以气泡从不出现，而函数本身的测试条条通过，因为没有一条测试问「谁调用它」。军师里还留了一个未定义变量，控制台每秒抛一次 \code{ReferenceError}——agent 改动时删掉了它的定义，留下了引用。这三条都不是读代码读出来的，只有我把页面打开、真打一局才看得见。

\subsection{界面上的问题，只有真的用起来才撞得上}

界面的不统一，每次都得我自己开页面对一遍，逐条说、逐条验。招式卡高矮不一，原因是一张卡里描述长短不同，整排跟着参差；对局页两侧标题长度不同，会把各自的筛选条推到不同的起点；「我方」两个字写在分屏标题里既没用又不对齐。我第一次说这件事时把方向指错了，agent 照着改了一遍间距，问题还在，真正管用的是给标题固定宽度。这些改动的代码量都很小，难的是我每次只能指出我看到的那一处，agent 就只改那一处，下一次我再看见另一处。

重复的信息也是这样。出征页顶部的徽标写着「训练 · PVE」，右栏又写了一遍同样的模式；回合结算后，横幅把刚在动画里念过、也已经写进战斗记录的那一帧复述一遍；最严重的一次，一段老师的讲解同时出现在顶部条、左下浮层和右下气泡三处，文字一模一样。同一个动作在界面上还有三个名字：标签写「认输」，按钮写「确认撤退」，战斗记录里又写成「撤退」。这类问题逐处看页面是看不完的，得把玩家可见的文案集中到一张表上逐条对，「同一件事」才浮出来。

\subsection{验收要在真浏览器里真打一局，口径也要核}

我的做法是加两层检查，都不进 \code{npm test}——需要浏览器的检查不该当成必过门。第一层是接线检查（\code{wiring.test.js}）：\code{app.js} 里每个 \code{\$('id')} 都必须在 \code{index.html} 或 \code{app.js} 自建的元素里存在，面试题要求的每项能力都必须找得到入口。第二层是冒烟测试：无头浏览器从营地选人、逐回合出招、打到结算，断言页面渲染出伙伴卡、对局有结果、控制台零报错。

检查只能验证断言本身，验证不了断言在数什么；有几处缺陷的代码完全正常，错的是口径。玩家补位的那一回合本来就不该出招，却被计成一次「引擎兜底」，方向恰好让对手显得比实际更差。犹豫判定用的是「距第一次悬停的墙钟时间」：我在火花上停了一下，然后移去对方面板操作了 13 秒，回来碰「防御」，界面就弹出「你在火花和防御之间停留了 13 秒」——那 13 秒我根本没在看这两个选项。信号要量的是花在这上面的时间，不是经过了多少时间。这两处不会让任何测试失败，只能逐条核对分子分母才能发现。

比漏改更麻烦的是：用来兜底的检查本身就不起作用。冒烟测试里的伙伴卡数量写死过，宠物增加之后那个数字不再对得上；语义检索的语料是手工维护的第三份副本，卡片改了它不知道；工具参数用合法行动列表的下标，而索引会随能量、道具和倒下整体位移，同一个下标在不同回合指向不同行动。玩家文案里不许出现「启发式」「枚举」这类内部词，这一条我提了要求，agent 照此写出了禁止词表检查，但它的检查有盲区，是我在核对时发现的：它取局内提示时没有传事件参数，那条理由的正文根本不在覆盖范围内，把它换成错话检查也照样通过。按我的意见换成静态扫描，逐行取 \code{coach/} 下的中文字面量对词表，一跑就扫出四处真泄漏。

这几条形态不同、毛病一样：检查写死了预期值，或者与被测对象不同源，或者只覆盖跑得到的那条路。所以每写完一条检查，我会先做一次反向验证，把错的东西放进去，看它会不会失败；再让期望值从被测对象自己推导，不从手写的常量来。agent 的每一次交付都配着一句「已完成」，而我每次都得自己再验一遍；光重申没有用，只能把它变成机械检查。
