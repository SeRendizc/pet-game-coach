\section{运行与使用}

代码在 \url{https://github.com/SeRendizc/pet-game-coach}。核心 Demo 使用 Node.js 20+，没有第三方 npm 运行依赖；语义检索和离线模型实验另有 Python 与模型依赖。

\begin{itemize}[leftmargin=1.5em,itemsep=0em,topsep=0.15em]
\item \code{npm start}：启动，浏览器打开 \url{http://127.0.0.1:8765/} 就能玩
\end{itemize}

不接模型也能完整游玩，规则建议、复盘和小测都由本机引擎给。想接模型，就打开 \url{http://127.0.0.1:8765/connect.html} 填上 DeepSeek API Key，密钥只留在后端进程内存里；也可以先跑一次 \code{./scripts/start.sh --save-key} 存进钥匙串。

想看某个能力：营地里是培养和配招，出征先选关卡再挑三只伙伴；对局里，军师和老师的提示条在战斗区顶部、动作面板之上，点「看看原因」能看到依据，陪练在左下角的气泡和聊天里；一局打完看复盘和关键回合，培养页有加点对照和小测。
