\subsection{工具决策三轮真实评测}

完整表格在“难点”一节，这里只记两条最该被追问的数。把“默认停止”写进提示词之后，多余工具调用率从 75.0\% 降到 33.3\%，模型自停率从 3.23\% 升到 96.8\%，严格正确率从 31.25\% 升到 50.0\%——但漏调从 0 升到 21.9\%。这不是纯改善，是换了一种错法。再往后加“必须调用”字段的那一轮更差（漏调 77.3\%），已经回退。44 条用例里只有 32 条可判定，每格 1 条、单次运行，所以这些差值都没有置信区间。

最好的一臂相对关键词基线高 2.68 个百分点（112 条正解里 5 胜 2 负），McNemar 精确检验 $p = 0.4531$，配对 bootstrap 95\% 置信区间 $[-1.79, +7.14]$ 个百分点，跨零。也就是说：没有证据表明它更好，只能说没有证据表明它更差。

两个必须一起读的口径。一是这 128 条查询全部由我手写、我自己标注，不是独立盲标集——沿用下来的 20 条旧查询 Hit@3 是 81.25\%，新写的 92 条是 93.48\%，高出的约 12 个百分点就是出题人知道答案的代价，所以绝对数字偏乐观。二是负例拒答三个检索臂完全一样，都是 56.25\%，这是本轮真正测出来的问题，不是臂之间的排序。

\subsection{平衡矩阵}

用新的相克表重跑：5{,}796 场、398 个臂、181.6 秒，规则版本 0.6，脚本 \path{scripts/eval-balance-matrix.js}，不调用模型。胜负平是 1997 / 3764 / 35。

结论是\textbf{没有哪只宠物被证明明显更强}。同属性的六组配对在主要对照里全部未分离；旧规则下唯一统计显著的同类失衡（雷系两只之间相差 33.3 个百分点、置信区间不重叠）在新表下缩到 8.3 个百分点，区间重叠，消失了。九套阵容的胜率极差也从旧表的 63.0 个百分点收窄到 35.2 个百分点。

能确定的只有节奏效应，以及一堆“这批数据回答不了”：每格 12 到 60 场，小于约 12 到 15 个百分点的胜率差分不开；玩家侧是 8 个固定脚本策略，不是真人；全部对局 1 级、0 加点。所以矩阵能证明的是“那条显著差距消失了、离散度收窄了”，\textbf{不能}证明“属性平衡整体变好”——那需要跨属性对照和消融实验。这是我自己报告里的原话，我没有把它读成好消息。

各有两处必须说明的地方。干预策略的回报更高，但它的\textbf{帮助次数反而更少}（1.70 对 5.89 次每局），增量帮助也更低（0.86 对 1.38）——它赢在打扰成本，不是赢在教得更好，这两件事不能混着讲；而且这些都是模拟玩家的口径，不等于真人学习效果。另外这一轮跑在规则版本 0.5 上，比现在的 0.6 早一个版本，我没有重跑。工具选择实验的 16 条测试全部是英文、二选一、共 24 条训练样本，它证明的是“参数确实更新了、并且学到了这个窄任务”，不是“模型会选工具”。两个实验都做了奖励投机审计：总是提示、从不提示、只帮容易场景、只按风险提示这四种策略都单独跑过，没有出现靠刷指标拿高回报的情况。

\subsection{接线自检与浏览器冒烟}

\code{wiring.test.js} 离线跑，查 id 存在性、死函数清单、以及五个角色入口是否连着；\code{npm run test:smoke} 用 headless Chrome 真打一局训练赛，断言营地渲染出 12 张伙伴卡、比赛打到结果、控制台零报错。后者故意不进 \code{npm test}。这两条的由来和各自的盲区写在“难点”一节。

\subsection{真实模型调用}

上面三轮评测的 44 条用例全部是真实 API 调用。除此之外的行为采集里，已验证的包括 PVP 前置拒绝在 3 毫秒内本地返回、不产生上游调用；已发现的缺陷是把净化药说成“解药”、能量果说成“以太”，而数字校验没有拦住——这一条直接导致了后来加的名称校验与因果校验。
